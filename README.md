To open both the API and client applications in Visual Studio, follow these steps:
For the API Application:
1.	Locate the API Project Folder:
o	Navigate to the directory where your API project is located. For example, if your project is named DebraEventServiceAPI, go to that folder.
2.	Open the Project in Visual Studio:
o	Right-click on the .sln (solution) file (e.g., DebraEventServiceAPI.sln).
o	Select Open with Visual Studio or just Open.
3.	Build the API Project:
o	Once the project is open in Visual Studio, go to the menu bar and select Build > Build Solution to compile the project and ensure there are no errors.
4.	Run the API Project:
o	Press F5 or click the green play button to start debugging the API. The API will run on a local development server (e.g., https://localhost:5001/).
For the Client Application:
1.	Locate the Client Project Folder:
o	Navigate to the directory where your client application project is located. For example, if your project is named DebraEventServiceClient, go to that folder.
2.	Open the Client Project in Visual Studio:
o	Similar to the API project, right-click on the .sln (solution) file (e.g., DebraEventServiceClient.sln).
o	Select Open with Visual Studio or just Open.
3.	Build the Client Project:
o	After opening the project in Visual Studio, go to Build > Build Solution to compile the project.
4.	Run the Client Application:
o	Press F5 or click the green play button to start debugging the client application. The client application will run, and the web interface should open in your default browser.
